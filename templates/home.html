Welcome to the Image Processing & Classification API

Test the endpoints of the application in the interactive documentation (/docs).

Health check: /health

Available Endpoints

  • GET /health - Service health check (returns {"status": "ok"}).
  • GET /classes - List all supported classification categories.
  • POST /predict - Classify an uploaded image (multipart/form-data).
  • POST /resize - Resize an uploaded image to given width and height.
  • POST /grayscale - Convert an uploaded image to grayscale.
  • POST /rotate - Rotate an uploaded image by angle degrees.
